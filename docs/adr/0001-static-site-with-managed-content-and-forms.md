# Sitio estático con contenido gestionado y formularios externos

Escuadra Arquitectura usará un frontend estático, un CMS visual para gestionar los casos de proyecto y Google Forms/Sheets para capturar consultas. Se descarta un backend propio y una sincronización en vivo con Instagram: el sitio necesita ser rápido y fácil de mantener por personas no técnicas, sin añadir la carga operativa de un servidor o de tokens de Meta.
